기초 인공신경망

입력(문제)과 출력(정답)을 알려 주면, 인공신경망이 스스로 규칙을 찾아 배웁니다. 학습하는 모습을 그래프와 그림으로 직접 확인할 수 있습니다.

처음 사용하는 분을 위한 설명

인공신경망은 사람 뇌의 신경세포(뉴런)를 흉내 낸 계산 방법입니다. 사람이 규칙을 직접 알려 주지 않아도, 문제와 정답을 여러 개 보여 주면 스스로 규칙을 찾아냅니다.

뉴런 하나가 하는 일은 간단합니다. 들어온 값마다 중요도(가중치)를 곱해서 모두 더하고, 그 결과를 활성화 함수에 통과시켜 다음 뉴런에게 넘깁니다.

학습은 다음 과정을 수천 번 반복하는 것입니다.

  1. 지금 가중치로 답을 예측합니다.
  2. 예측과 정답이 얼마나 다른지(오차) 계산합니다.
  3. 오차가 줄어드는 방향으로 가중치를 조금씩 고칩니다. (역전파)

사용 순서: ① 데이터 입력 → ② 신경망 구조 정하기 → ③ 학습 시작 → ④ 결과 확인 및 새로운 값 넣어 보기

① 데이터 입력

입력은 문제, 출력은 정답입니다. 한 줄이 문제 하나입니다.

예시 데이터 불러오기

여러 값 한 번에 붙여넣기

② 신경망 구조

입력과 출력 사이에서 생각을 담당하는 층입니다. 0개이면 직선 같은 단순한 규칙만 배울 수 있습니다.

뉴런이 많을수록 복잡한 규칙을 배울 수 있지만, 학습이 느려질 수 있습니다.

③ 학습 설정

한 번에 가중치를 얼마나 크게 고칠지 정합니다. 너무 크면 오차가 들쭉날쭉하고, 너무 작으면 학습이 느립니다. 0과 1을 맞히는 문제는 0.5, 숫자를 맞히는 문제는 0.1 정도가 알맞습니다.

데이터 전체를 몇 번 반복해서 공부할지 정합니다. 한 번 반복하는 것을 에포크(epoch)라고 합니다.

학습 결과에는 영향이 없고, 학습 과정을 화면에 보여 주는 속도만 바뀝니다.

신경망 모양

동그라미는 뉴런, 선은 뉴런 사이의 연결(가중치)입니다. 학습하는 동안 선의 색과 굵기가 바뀌는 모습을 볼 수 있습니다.

양수 가중치 (값을 키움) 음수 가중치 (값을 줄임) 선이 굵을수록 영향이 큽니다

오차 그래프

학습이 잘 되면 선이 오른쪽으로 갈수록 아래로 내려갑니다.

신경망이 배운 모양

파란 점은 입력한 데이터, 빨간 선은 신경망이 예측한 값입니다. 학습이 진행될수록 선이 점들을 따라갑니다.

학습 결과

각 문제에 대해 정답과 신경망의 예측을 비교합니다.

⑤ 새로운 값 넣어 보기

학습에 쓰지 않은 새로운 입력을 넣으면, 신경망이 배운 규칙으로 출력을 예측합니다.

신경망이 숫자의 크기에 휘둘리지 않도록, 계산할 때는 입력값을 −1~1, 출력값을 0~1 범위로 바꿔서 학습합니다. 이를 정규화라고 하며, 화면에는 다시 원래 크기로 되돌려 보여 줍니다. 출력층은 정답이 0과 1뿐인 문제(AND, XOR 등)에서는 시그모이드 함수를, 일반 숫자를 맞히는 문제에서는 계산한 값을 그대로 내보내는 방식을 사용합니다.
