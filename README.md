# 기초 인공신경망 프로그램

입력(문제)과 출력(정답)을 알려 주면, 인공신경망이 **스스로 규칙을 찾아 배우는** 프로그램입니다.
학습하는 모습을 그림과 그래프로 직접 확인할 수 있습니다.

---

## 🖱️ 사용 방법

1. **데이터 입력:** 왼쪽 표에 입력(문제)과 출력(정답)을 적습니다. 처음이라면 `AND`, `XOR` 같은 **예시 데이터** 버튼을 눌러 보세요.
2. **신경망 구조 정하기:** 은닉층 개수, 층마다 뉴런 수, 활성화 함수를 고릅니다.
3. **학습 시작:** `학습 시작` 버튼을 누르면 오차가 줄어드는 모습과 연결선의 변화를 볼 수 있습니다.
4. **결과 확인:** `학습 결과` 표에서 정답과 예측을 비교합니다.
5. **새로운 값 넣어 보기:** 학습에 쓰지 않은 값을 넣어 신경망이 어떻게 예측하는지 확인합니다.

> 💡 `1번만 학습` 버튼을 누르면 데이터 전체를 딱 한 번만 공부합니다. 선의 색과 굵기가 조금씩 바뀌는 모습을 천천히 관찰할 수 있습니다.

---

## 🧠 인공신경망이란 무엇입니까?

**사람 뇌의 신경세포(뉴런)를 흉내 낸 계산 방법**입니다.

보통 프로그램은 사람이 규칙을 직접 적어 줍니다. 예를 들어 "화씨 = 섭씨 × 1.8 + 32"라고 알려 줘야 합니다.
인공신경망은 반대입니다. 규칙은 알려 주지 않고 **문제와 정답만 여러 개 보여 주면**, 스스로 규칙을 찾아냅니다.

| | 보통 프로그램 | 인공신경망 |
|---|---|---|
| 사람이 주는 것 | 규칙 | 문제와 정답 |
| 컴퓨터가 하는 일 | 규칙대로 계산 | 규칙을 스스로 찾음 |

---

## ⚪ 뉴런 하나가 하는 일

뉴런은 아주 간단한 계산만 합니다.

1. 들어온 값마다 **가중치(중요도)** 를 곱합니다.
2. 모두 더하고 **편향**이라는 숫자를 더합니다.
3. 그 결과를 **활성화 함수**에 통과시켜 다음 뉴런에게 넘깁니다.

```
출력 = 활성화함수( 입력1 × 가중치1 + 입력2 × 가중치2 + 편향 )
```

> 🍜 **비유:** 라면 맛을 정할 때 "물 양은 매우 중요(가중치 큼), 파는 조금 중요(가중치 작음)"처럼 재료마다 중요도가 다릅니다. 신경망은 이 **중요도를 스스로 알맞게 맞춰 가는 것**이 학습입니다.

---

## 🏗️ 신경망의 구조

```
입력층  →  은닉층  →  출력층
(문제)     (생각)     (답)
```

| 층 | 하는 일 |
|---|---|
| **입력층** | 문제(입력값)를 받습니다. |
| **은닉층** | 입력을 조합해 규칙을 찾아내는 "생각"을 합니다. |
| **출력층** | 최종 답을 내보냅니다. |

프로그램의 `신경망 모양` 그림에서
- **파란 선**은 양수 가중치(값을 키움),
- **빨간 선**은 음수 가중치(값을 줄임),
- **굵은 선**일수록 영향이 큰 연결입니다.

---

## 📚 신경망은 어떻게 배웁니까?

다음 세 단계를 수천 번 반복합니다.

1. **예측하기:** 지금 가중치로 답을 계산합니다. (처음에는 가중치가 무작위라서 엉터리 답이 나옵니다.)
2. **오차 계산하기:** 예측이 정답과 얼마나 다른지 계산합니다.
3. **가중치 고치기:** 오차가 줄어드는 방향으로 가중치를 **조금씩** 고칩니다. 출력층에서 입력층 쪽으로 거꾸로 거슬러 올라가며 고치기 때문에 **역전파**라고 부릅니다.

> ⛰️ **비유:** 안개가 낀 산에서 가장 낮은 곳을 찾아 내려간다고 생각해 보세요. 발밑의 기울기만 보고 낮은 쪽으로 한 걸음씩 내려가면 결국 골짜기에 도착합니다. 이 방법을 **경사하강법**이라고 합니다. 여기서 골짜기는 "오차가 가장 작은 곳"입니다.

## ⚙️ 설정 항목 설명

| 설정 | 뜻 | 팁 |
|---|---|---|
| **은닉층 개수** | 생각하는 층의 개수 | 0개이면 직선 같은 단순한 규칙만 배웁니다. |
| **층마다 뉴런 수** | 한 층에 있는 뉴런 수 | 많을수록 복잡한 규칙을 배울 수 있습니다. |
| **활성화 함수** | 뉴런의 계산 결과를 바꾸는 함수 | 아래 표를 참고하세요. |
| **학습률** | 한 번에 가중치를 고치는 크기 (산에서 내딛는 보폭) | 0/1 문제는 0.5, 숫자 문제는 0.1 정도가 알맞습니다. |
| **반복 횟수 (에포크)** | 데이터 전체를 공부하는 횟수 | 오차가 충분히 줄지 않으면 늘려 보세요. |

### 활성화 함수

| 이름 | 하는 일 | 특징 |
|---|---|---|
| **시그모이드** | 값을 0~1 사이로 바꿈 | 가장 오래된 기본 함수입니다. |
| **tanh** | 값을 −1~1 사이로 바꿈 | 시그모이드보다 학습이 빠른 편입니다. |
| **ReLU** | 음수는 거의 0으로, 양수는 그대로 | 요즘 가장 많이 쓰는 함수입니다. |

> ❓ **활성화 함수가 왜 필요합니까?**
> 활성화 함수가 없으면 층을 아무리 많이 쌓아도 결국 직선 하나와 같아집니다. 활성화 함수가 값을 **휘게** 만들어 주기 때문에 곡선이나 복잡한 규칙도 배울 수 있습니다.

## 🔍 예시 데이터

| 예시 | 내용 | 관찰할 점 |
|---|---|---|
| **AND** | 두 입력이 모두 1일 때만 1 | 은닉층이 없어도 배울 수 있습니다. |
| **OR** | 입력 중 하나라도 1이면 1 | 은닉층이 없어도 배울 수 있습니다. |
| **XOR** | 두 입력이 서로 다를 때만 1 | ⭐ **은닉층이 꼭 필요합니다.** |
| **섭씨 → 화씨** | 화씨 = 섭씨 × 1.8 + 32 | 신경망이 직선 규칙을 찾아냅니다. |
| **곡선 (y = x²)** | 포물선 모양 | 은닉층이 휘어진 모양을 만들어 냅니다. |

### ⭐ XOR 실험 해 보기

XOR은 인공신경망 역사에서 아주 유명한 문제입니다.

1. `XOR` 예시를 불러옵니다.
2. **은닉층을 0개**로 바꾸고 학습합니다. → 아무리 오래 학습해도 오차가 줄지 않고, 4문제를 모두 맞히지 못합니다.
3. **은닉층을 1개**로 바꾸고 다시 학습합니다. → 4문제를 모두 맞힙니다.

**왜 그럴까요?** XOR의 정답을 좌표에 찍으면, 1인 점과 0인 점을 **직선 하나로 나눌 수 없습니다.** 은닉층이 없는 신경망은 직선 하나만 그을 수 있어서 실패합니다. 은닉층을 넣으면 여러 개의 선을 조합할 수 있어서 문제를 풀 수 있습니다.

## ⚠️ 알아 두면 좋은 점

- **처음 가중치는 무작위입니다.** 그래서 같은 설정이라도 학습할 때마다 결과가 조금씩 다를 수 있습니다. 결과가 이상하면 `처음부터 다시`를 눌러 보세요.
- **배운 범위 밖은 잘 모릅니다.** 0~40도만 배웠는데 100도를 물어보면 크게 틀릴 수 있습니다.
- **정규화:** 신경망이 숫자의 크기에 휘둘리지 않도록, 계산할 때는 입력을 −1~1, 출력을 0~1 범위로 바꿔서 학습하고, 화면에는 원래 크기로 되돌려 보여 줍니다.
- **출력층:** 정답이 0과 1뿐인 문제는 시그모이드 함수를, 일반 숫자를 맞히는 문제는 계산한 값을 그대로 내보냅니다.
- **학습이 망가질 때:** 오차가 갑자기 커지면 학습률이 너무 큰 것입니다. 학습률을 낮추고 다시 시작하세요.
